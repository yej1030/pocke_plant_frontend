# Pocket Plant

## 연결한 휴대폰에서 실행

Node 22.12 이상에서 `npm ci` 후 `npm run phone`을 실행하거나 VS Code의 **연결된 안드로이드에서 실행** 작업을 선택합니다. Android Platform Tools의 `adb`가 PATH에 있어야 합니다. 또는 로컬 `.env.local`에 `ADB_PATH`를 지정합니다.

USB 디버깅을 허용한 휴대폰 한 대와, 같은 네이티브 라이브러리로 만들어진 `com.pocketplants` 개발용 앱이 필요합니다. 실행 도구는 USB로 Metro에 연결하고 수정한 JavaScript 화면을 기존 설치본에서 실행합니다. 계정 데이터를 삭제하거나 앱을 제거하지 않습니다. 최초 설치나 네이티브 의존성이 달라졌을 때는 Android SDK/NDK를 준비한 뒤 `npm run android`로 빌드·설치해야 합니다. USB와 PC 개발 서버는 실행 중 유지해 주세요.

앱이 이미 켜져 있어도 실행할 때 Metro의 표준 다시 읽기 요청을 보내 최신 화면 코드를 반영합니다. 이 요청은 앱 데이터를 지우거나 로그아웃시키지 않습니다.

휴대폰의 질병 예측 요청은 기존 사용자 로그인을 거쳐 **AWS → 모델 게이트웨이 → PC 모델**로 전달됩니다. 모델 서버의 비밀키는 앱에 넣지 않습니다. 질병 결과에는 후보별 특징·확인 및 조치를 표시하며, 모델 비교 점수를 검증된 발병 확률로 표시하지 않습니다.

## 브라우저에서 실행

휴대폰이 없으면 `npm run web`으로 질병 화면만 브라우저에서 실행할 수 있습니다. 실제 React Native 화면을 공유하고, 모델 요청만 로컬 개발 프록시로 전송합니다. 이 실행은 휴대폰 로그인 흐름을 대신하지 않습니다. 설정과 차이는 [web/README.md](web/README.md)를 참조하세요.
